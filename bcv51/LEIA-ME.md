27 clips analisados (C0911–C0937), cerca de 4 minutos. Rough cut de **45 s**, 1080p, 23.976.

## Ficheiros
- `BCV51_teste_v1.xml`: montagem com efeitos (push-in lento, 2 dissolves, fade in/out)
- `BCV51_teste_v1_so_cortes.xml`: a mesma montagem só com cortes (usa se o outro der erro)

## Como abrir no Premiere
1. File → Import → `BCV51_teste_v1.xml`
2. Os clips aparecem offline → botão direito → **Link Media** → aponta para a pasta dos originais (C0911.MP4 …)
3. Se os originais forem 4K: seleciona tudo na timeline → **Set to Frame Size**
