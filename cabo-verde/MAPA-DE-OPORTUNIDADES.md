## 2. Projetos

### A. Solução de e-mail / IT para instituições públicas (mais rápido a gerar receita)
- **Primeiro passo:** diagnóstico do problema do Carlos Dias (domínio, servidor atual,
  número de contas, spam, falhas de entrega, backups, acesso móvel).
- **Oferta provável:** migração para Microsoft 365 ou Google Workspace (ambos têm
  preços para governo/educação), configuração SPF/DKIM/DMARC, formação, suporte mensal.
- **Modelo de negócio:** taxa de implementação + contrato de suporte mensal.
- **Atenção:** contratos públicos passam por regras de contratação pública —
  confirmar com ele qual o procedimento (ajuste direto, consulta, etc.).
- **Parceiro natural:** o ex-engenheiro da CV Telecom.

### B. Menu Real + integração ERP
- Pedir ao responsável do ERP: documentação da API, ambiente de testes, regras de
  faturação eletrónica em vigor em Cabo Verde.
- Uma integração bem feita pode virar **produto reutilizável** para outros
  restaurantes/negócios que usam o mesmo ERP.

### C. Transporte de cargas interilhas (o maior)
- Peças: terrestre (já pensado) + **marítimo** (faltava).
- O sistema portuário que a ENAPOR usa provavelmente já tem dados de escalas,
  navios e cargas. **Não é preciso competir com ele — é preciso integrar-se.**
- Perguntas para o Capitão dos Portos:
  1. Qual o nome exato do sistema e do fornecedor?
  2. Existe API ou forma oficial de aceder a dados (horários, escalas, manifestos)?
  3. Quem na ENAPOR decide sobre acessos/parcerias?
  4. Qual o maior problema hoje para quem envia carga entre ilhas
     (reserva, rastreio, documentação, pagamento, atrasos)?
- Valor para o utilizador final: **um sítio só** para reservar, pagar e seguir a
  carga de porta a porta entre ilhas.
